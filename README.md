# 足し算パズル

合計がお題の数になるように、盤面の数字を繋げて消す。90秒でどれだけ消せるかを競う暇つぶし用パズル。
仕様は [spec.md](spec.md) にある。

ブラウザで動く PWA。ビルド無しの素の ES モジュールで書いてあるので、このディレクトリをそのまま静的配信すれば動く。

## 動かす

```sh
npm start     # http://localhost:8080
npm test      # ゲームロジックのテスト
npm run icons # icons/*.png を作り直す
```

スマホで遊ぶときは、同じネットワークから `http://<PCのIP>:8080` を開いてホーム画面に追加する。
Service Worker は `https` か `localhost` でしか登録されない（無くても遊べる）。

## 構成

ロジックと表示を分けてある。`src/game/` は DOM も localStorage も触らないので、後でネイティブに作り直すときも中身を使い回せる。

```
src/game/config.js     お題・盤面サイズ・制限時間などの定数。数値を調整するならここ
src/game/rng.js        乱数（テストから固定シードを差し込めるようにしてある）
src/game/board.js      盤面、繋げられるセルの表、消去→落下→補充
src/game/solver.js     成立可能な組み合わせが存在するかの判定
src/game/generator.js  盤面の生成と、詰んだときの組み直し
src/game/game.js       1セッション。チェイン・スコア・時間
src/app/storage.js     自己ベストと設定（ローカル保存のみ）
src/app/board-view.js  盤面の描画となぞり操作
src/app/main.js        ホーム / プレイ / 結果の画面遷移
```

## 実装で決めたこと

仕様に書かれていないぶんの判断。

- **消えるのは指を離したとき**。合計がぴったり一致してもその場では消さない。なぞっている途中で
  たまたま一致したときに、戻って別の繋ぎ方に変える余地を残すため。一致している間は盤面の下の
  合計の色が変わる
- **なぞりの間を補間する**。指を速く動かしても、前回位置からの線分を刻んで通過したセルを拾う。
  速さで結果が変わらないようにするため
- **なぞっている最中に反応する範囲は、セルに内接する円**。四隅は反応しない。斜め2マスへ繋ぐには
  間のセルを避けて回り込む必要があり、その通り道として余白が要る（真っ直ぐなぞると間のセルの
  中心を必ず踏むため）。円の直径はセル幅の8割強で、44pt は確保している。
  なぞり始めだけはセル全体で受ける（押さえた場所が反応しないのは分かりにくいため）
- **描画は3層**（下からタイル → チェインの線 → 数字）。線をタイルの上に描くので、斜め2マスで
  間のセルを飛び越えたことが線で分かる。数字は線の上に来るので隠れない
- **詰み判定は探索を打ち切ったら「詰み」扱い**。遊べる盤面をたまに組み直してしまうことはあっても、
  詰んだ盤面を見逃すよりは害が小さい
- **テーマの切り替えをホームに置いた**。仕様の Settings に theme があるのに変える場所が無かったため。
  小さな文字ボタン1つに留めてある

## テスト

```sh
npm test
```

詰み判定（`solver.js`）は 3x3 盤面で総当たりと突き合わせて検証している。他は盤面の落下・補充、
チェインのルール、自己ベストの保存。

## 未決事項（spec 8章）の状況

3つとも実際に遊んで確定させた。

1. **お題の候補** — 10〜25 の1刻み（16通り）にした
2. **盤面サイズ** — 5×6 は窮屈だったので 4列×5行 にした
3. **数字の出現分布** — 等確率のまま。4×5・お題10〜25 でランダムな盤面を各5000通り試したところ、
   成立する組み合わせが存在しない盤面はお題10で1回だけ（他は0回）だった。組み直しはまず発生しない
